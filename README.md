# Uday Radadiya

Personal portfolio: https://udayyyyy.github.io/

Static HTML, CSS, and JavaScript. GitHub Pages publishes the root of the `main` branch; no build step is required.

Edit `index.html` for content, `styles.css` for appearance, and `script.js` for interactions. The résumé and artwork are in `assets/`.

The abstract artwork is an original adaptation inspired by Barbara Hepworth’s [Pierced Hemisphere I](https://hepworthwakefield.org/our-art-artists/collections/highlights/pierced_hemisphere_i/).
